# 抽样稳定性实验报告

> 日期 2026-08-20 · 工具 `backend/tools/experiment_sampling_stability.py`（`sampling_stability_v1`）
> 数据口径：解析运行 `jdparse_1f3a11846d1414dae0106a7a`（词表 v1.2），可聚类特征 2,736 份
> 抽样种子 20260820（冻结）

## 0. 为什么必须先做这个实验

岗位动态更新模块报告的每一次 `born` / `ended` / 能力变更，都可能有两个来源：
**岗位真的变了**，或者**只是这次抽到的 JD 不同**。在不知道后者有多大之前，
前者的任何数字都无法解释。

本实验不证明方法有效，它给出的是**判据**：多大的变化才算信号。

## 1. 方法

三种模式，全部在内存中运行（不落库、不产生运行记录），复用线上同一套聚类算法、
相似度函数与谱系判定函数（`_continued_matches`，阈值参数化后实验与线上共用）。

| 模式 | 抽样方式 | 匹配方式 | 回答的问题 |
| --- | --- | --- | --- |
| `structure` | 不相交对半 | 簇质心相似度 | 岗位结构是语料的性质，还是这次抽样的性质 |
| `lineage` | 两个重叠子样本 | 成员集合 Jaccard | 谱系会把多少抽样噪声报成 born / ended |
| `threshold` | 同上 | 扫描 Jaccard 阈值 | 0.55 处在曲线的什么位置 |

**口径说明**：两个子样本各自独立向量化，IDF 权重因此不同。这是刻意的——真实的第二次
采集本来就会重算 IDF，共用一套 IDF 会高估稳定性。

```bash
python -m tools.experiment_sampling_stability --parse-run-code <run> --mode structure
python -m tools.experiment_sampling_stability --parse-run-code <run> --mode lineage
python -m tools.experiment_sampling_stability --parse-run-code <run> --mode threshold
```

---

## 2. 结果

### 2.1 结构复现性（不相交对半）

两半没有任何共同 JD，各自独立聚类后按质心互相匹配：

| 项 | 值 |
| --- | ---: |
| 左半 / 右半 参与聚类 JD | 708 / 689 |
| 左半 / 右半 达标簇数（≥2 成员） | 123 / 107 |
| **在另一半中能找到对应簇的比例** | **57.7%** |
| 最近质心相似度 均值 | 0.456 |
| 最近质心相似度 p25 / p50 / p75 | 0.344 / 0.419 / 0.531 |

判定"有对应"的阈值取线上分配阈值 0.391。

### 2.2 谱系噪声下限（重叠子样本）

两个子样本各取全量 80%，实际共享 80.3%。**语料是同一批，此处报出的
born / ended 全部是抽样噪声，不含任何真实演化**：

| 项 | 值 |
| --- | ---: |
| 前代 / 本代 达标簇数 | 185 / 200 |
| continued | 119（**59.5%**） |
| born（噪声） | 81 |
| ended（噪声） | 66 |
| 匹配簇的平均成员重合度 | 0.858 |

**40.5% 的簇在纯抽样扰动下失去了谱系连续性。**

### 2.3 噪声不来自小簇

提高簇规模下限并不改善，反而略微变差：

| 簇规模下限 | 达标簇数（前/本） | continued | 延续率 |
| ---: | --- | ---: | ---: |
| 2 | 185 / 200 | 119 | 59.5% |
| 3 | 100 / 103 | 54 | 52.4% |
| 5 | 50 / 49 | 25 | 51.0% |
| 8 | 24 / 22 | 11 | 50.0% |

排除了"小簇天然脆弱"这一解释。**不稳定性存在于聚类划分本身，不是成员抽样的边缘效应。**

### 2.4 阈值敏感性：无自然断点

| Jaccard 阈值 | continued | born | ended | 延续率 | 匹配簇平均重合度 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.30 | 150 | 50 | 35 | 75.0% | 0.767 |
| 0.40 | 137 | 63 | 48 | 68.5% | 0.807 |
| 0.45 | 130 | 70 | 55 | 65.0% | 0.828 |
| 0.50 | 129 | 71 | 56 | 64.5% | 0.831 |
| **0.55（线上）** | **119** | **81** | **66** | **59.5%** | **0.858** |
| 0.60 | 114 | 86 | 71 | 57.0% | 0.871 |
| 0.65 | 108 | 92 | 77 | 54.0% | 0.885 |
| 0.70 | 83 | 117 | 102 | 41.5% | 0.951 |
| 0.80 | 73 | 127 | 112 | 36.5% | 0.980 |

曲线平滑，**不存在能把噪声消掉的阈值**——即使放宽到 0.30，仍有 25% 的簇被判为
born / ended。同时匹配簇的平均重合度始终很高（0.77–0.98），说明分布是**双峰**的：
簇要么匹配得很好，要么完全对不上，中间没有过渡带。

这解释了 §2.3：不是成员边缘性地增减，而是**约四成的簇在两次运行中被重新划分**。

### 2.5 语料变动 → 结构变动的敏感性

| 子样本比例 | 实际共享 | 达标簇数（前/本） | continued | 延续率 | 噪声（born+ended） |
| ---: | ---: | --- | ---: | ---: | ---: |
| 0.99 | 99.0% | 230 / 231 | 220 | 95.2% | 21 |
| 0.95 | 95.0% | 219 / 221 | 188 | 85.1% | 64 |
| 0.90 | 90.0% | 204 / 217 | 169 | 77.9% | 83 |
| 0.80 | 80.3% | 185 / 200 | 119 | 59.5% | 147 |

**退化是平滑且近似线性的，不是混沌的。** 斜率约为 2：

> **语料每变动 1%，约 2% 的簇失去谱系连续性。**

---

## 3. 结论

### 3.1 可用的判据

由 §2.5 的斜率得到一条可操作的规则：

> **观测到的 `born` + `ended` 比例必须显著超过语料周转率的 2 倍，才能作为真实岗位演化的证据。**

例：若第二批采集与第一批共享 90% 的 JD（周转率 10%），则约 22% 的簇变动属于噪声；
只有超出这一水平的部分才可归因于岗位本身的变化。

### 3.2 对岗位动态更新模块的影响

系统当前累计的 `continued` 7,601 / `born` 5,411 / `ended` 2,029，以及 677 个演化事件，
**其中相当比例落在噪声范围内**。这些数字可以作为机制运行正常的证据，
但不能作为"观测到岗位演化"的证据。

### 3.3 结构复现性偏低

§2.1 的 57.7% 说明：在半量语料（约 700 份 JD）下，岗位结构的可复现性只有中等水平。
这与 §2.4 的双峰分布指向同一个原因——**聚类划分对输入组成敏感**。

---

## 4. 局限

- 本实验测的是**抽样扰动下的稳定性**，不能替代真实时间维度的验证。真实的第二次采集
  除组成变化外还包含岗位本身的变化，两者叠加，本实验只标定了其中一项。
- 子样本由同一批语料抽取，其分布与真实的第二批采集不完全相同（后者可能有系统性偏移，
  如新公司进入、某类岗位集中发布）。因此 §3.1 的判据是**下限**，真实噪声可能更高。
- 结果依赖当前的特征表示与聚类参数。任一变更后需重跑本实验重新标定判据。

---

## 5. 下一步

本实验的结论指向两个方向，二者不冲突：

1. **降低划分不稳定性**——若聚类划分对输入组成不那么敏感，噪声下限会同步下降。
   §2.4 的双峰分布提示问题出在划分边界附近的 JD 归属上。
2. **在现有噪声水平下设计可用的演化判据**——不追求消除噪声，而是把 §3.1 的规则
   固化进演化事件的呈现，让每一条变更都带上"是否超过噪声下限"的标注。

留出重发现实验（验证新岗位发现的输出正确性）不受本结论阻塞，可并行进行。
