# 岗位化门槛 θ 的经验测量：否定结果

> 日期 2026-08-20 · 工具 `backend/tools/experiment_jobification_threshold.py`
> 推演运行 `discover_598674c1450843b89c04c0e7`（算法版本 v1_8）

## 0. 结论

**θ 无法从当前数据测出，且原因不是「关联不存在」，而是「成熟度在 L3 层没有区分度」。**

前瞻排序若要做，粒度必须从「岗位候选（L3 组合）」换到「技术类（L2）」。

---

## 1. 目的

现行 `emerging` 门控中的「技术成熟度 ≥ 0.35」是设定值。本实验试图用横截面关联把它
换成经验值：对每个 L3 技术点同时取技术侧成熟度与岗位侧出现规模，
看成熟度到什么水平时技术开始稳定进入招聘需求。

## 2. 结果

### 2.1 对照组方向相反

| 组 | 技术点数 | 已岗位化比例（≥3 份 JD） |
| --- | ---: | ---: |
| 有里程碑证据 | 188 | 42.0% |
| 无里程碑证据 | 54 | **46.3%** |

有技术里程碑的技术点，进入招聘需求的比例**略低于**没有里程碑的。

### 2.2 分箱曲线无单调性

| 成熟度区间 | 技术点数 | 已岗位化比例 |
| --- | ---: | ---: |
| 0.0–0.1 | 29 | 34.5% |
| 0.1–0.2 | 7 | 57.1% |
| 0.2–0.3 | 27 | 44.4% |
| 0.3–0.4 | 9 | 0.0% |
| 0.4–0.5 | 49 | 63.3% |
| 0.5–0.6 | 21 | 28.6% |
| 0.6–0.7 | 8 | 12.5% |
| 0.7–0.8 | 16 | 56.2% |
| 0.8–0.9 | 10 | 20.0% |
| 0.9–1.0 | 12 | 33.3% |

锯齿状，不存在阈值效应。工具报出的「拐点 0.4」只是相邻箱差值最大处，
其前一箱仅 9 个样本且岗位化率为 0，属小样本抖动，**不构成拐点**。

### 2.3 根因：成熟度在 L3 层是常数分块

里程碑的技术链接层级分布：

| 层级 | 直接挂载里程碑的节点数 |
| --- | ---: |
| L1 技术域 | 1 |
| L2 技术类 | 21 |
| **L3 技术点** | **0** |

**没有任何一条里程碑直接挂在 L3 上。** 因此全部 188 个有成熟度的 L3 节点，
其成熟度 100% 来自祖先继承，同一 L2 下的所有子节点取得完全相同的值：

| 成熟度取值 | 共享该值的 L3 节点数 |
| ---: | ---: |
| 0.445 | 28 |
| 0.789 | 16 |
| 0.501 | 13 |
| 0.912 | 12 |
| 0.282 | 11 |

成熟度最高的 10 个 L3 技术点全部为 0.912 / 101 条里程碑（同一祖先），
而它们的 JD 数从 176 一路降到 0——同一个成熟度对应着截然不同的岗位化程度。

> 横轴实际只有 21 个不同取值（对应 21 个有证据的 L2），且与 L3 层的实际情况无关。
> 在这样的横轴上测阈值，无论结果如何都没有意义。

---

## 3. 对前瞻排序设计的影响

| 原设计 | 状态 |
| --- | --- |
| θ 由数据测出 | ❌ 做不到。L3 无区分度；L2 仅 21 个样本，不足以拟合阈值曲线 |
| 成熟度跨阈时点 t\* | ⚠️ 只在 L2 层有意义 |
| t\* + 时滞先验 → 参考窗口 | ⚠️ 只能是「技术方向」级别，不是「岗位候选」级别 |
| 同类型内排序为纯数据驱动 | ⚠️ 仅在 L2 层成立 |

**可行的降级方案**：把前瞻排序做成**技术方向（L2）级别**——对 21 个有里程碑证据的
技术类给出前瞻排序与参考窗口，岗位候选按其涉及的技术类继承前瞻性。

这样表述也更贴合数据实际：我们有证据支撑的是「哪些技术方向即将产生岗位需求」，
而不是「哪个具体岗位何时出现」。θ 保留为设定值并明确标注。

---

## 4. 附带发现：成熟度维度此前一直失效

本实验开始前发现，里程碑技术链接全部指向 v1.1 节点，而推演自 v1.2 起跑在新节点上，
节点 id 逐词表版本独立，导致**最近所有推演运行的成熟度对所有节点恒为 0**。

后果：成熟度维度（评分权重 0.10）一直贡献 0；`emerging` 档的「成熟度 ≥ 0.35」
条件根本不可能满足。已在算法版本 v1_8 中按技术编码重映射修复，
修复后 2,365 个节点中 1,932 个取得非零成熟度。

> 这是同一类缺陷的第四次出现（`_nearest_role`、留出实验评测、岗位画像比较、里程碑链接）。
> 根因一致：**节点 id 被当作跨边界标识符使用，而它是逐词表版本独立的**。
> 凡跨越词表版本、跨越运行、跨越模块的比较，都必须使用技术编码。
