## 1. 最小实验范围（四项）

### E1　解耦生成与排序 🔴 最高优先

**为什么它排第一**：当前所有端到端指标都被排序失效污染。不先把生成与排序拆开，
后续任何消融的差异都会被排序噪声淹没，测了也不能归因。

**做法**：在同一遮蔽集上增加两条臂，与既有三条臂并列。

| 臂 | 生成 | 排序 |
| --- | --- | --- |
| 既有：本方法 | 频繁闭项集 | 证据门控评分 |
| 既有：频次基线 | JD 技术集合 | 支撑 JD 数 |
| **新增：混合臂** | **频繁闭项集** | **支撑 JD 数** |
| **新增：oracle 排序** | 频繁闭项集 | 与被遮蔽岗位的真实匹配度（上界） |

**预注册判据**：

- 若**混合臂 ≥ 频次基线** → 生成有价值，问题纯在排序。排序可改，方法论主张保留。
- 若**混合臂显著低于频次基线** → 频繁闭项集生成本身不如朴素方法，
  「粒度设计」这一贡献需要重新表述（它仍解决了测量分辨率问题，但不提升发现能力）。
- **oracle 臂给出排序改进的天花板**：若 oracle @10 仍很低，说明池子里虽有正确候选
  但极度分散，改排序的收益有限。

**成本**：低。两条臂都复用现有评测函数，无需改动线上代码。

---

### E2　候选画像扩展 🔴 已由 E1 触发，当前最高优先

**问题**：本方法候选是 2–5 个技术的**核心组合**，岗位画像是簇成员技术的聚合（中位 7 个）。
两者不在同一表示层级，对称 Jaccard 结构性够不到阈值。

**做法**：用支撑该候选的 JD 的技术集合，把核心组合扩展为完整画像，
使候选与岗位处于同一层级。扩展后重跑 E1 的全部臂。

**预注册判据**：对称 Jaccard 口径下本方法 Recall@25 从 0.0% 提升到 ≥ 18.8%（频次基线当前水平）
方可认为表示层级是主要障碍；若提升有限，说明问题不在表示而在排序或生成。

**触发条件**：已满足。E1 显示混合臂（95.8%）达到 oracle 上界且不劣于频次基线，
生成没有问题；且对称口径下 oracle 与本方法同为 8.3%，证明**排序已无改进空间，
差距完全来自表示层级**——这正是 E2 要解决的。

**成本**：中。需要改动候选构造，涉及线上代码与算法版本升级。

---

### E3　覆盖率度量消融：非对称 vs Jaccard 🟡

**验证的主张**：文档 4.1.2「非对称覆盖率优于 Jaccard」。

**做法**：把最近岗位比较的度量换成对称 Jaccard，重跑推演，比较：
①三档分类的分布；②留出实验的 Recall。

**预注册判据**：Jaccard 度量下应出现「候选完全落在某岗位能力集内、却因该岗位技术词更多
而被判为 potential_new_role」的案例。**若该类案例数为 0，则本主张在当前数据上无实证支持**，
文档应改为只陈述解析理由、不宣称实测优势。

**成本**：低。度量函数可参数化，不改其它逻辑。

---

### E4　门控消融：合取门控 vs 单一评分阈值 🟡

**验证的主张**：文档 7.1 贡献二「合取门控抗特定偏差」。

**做法**：用加权评分阈值替代合取门控重新分档，统计**带有「单一企业信号」或
「单一来源信号」风险旗标的候选中，有多少会被升到 emerging 档**。

**预注册判据**：合取门控下该数应为 0（条件不满足即不升档）。
若评分阈值下 > 0，则「抗特定偏差」得到机械性证实；若也为 0，
说明当前数据里不存在这种情形，主张缺乏实证支持，文档应弱化。

**注意**：这是**机械性质的证实**，不是质量主张——它证明门控确实挡住了某类候选，
不证明被挡住的候选就一定不该升档。

**成本**：低。分档函数已是纯函数，可直接对比。

## 2. 明确排除在最小范围之外

| 项 | 排除理由 |
| --- | --- |
| 成熟度模型的有效性验证 | 需要「某技术何时真正成熟」的外部依据，当前无法获得 |
| 双人标注升级抽取证据 | 需人工投入；现有单人标注已足够支撑版本对比这一用途 |
| 聚类划分稳定性改进 | 开放式算法问题，收益不确定，不阻塞核心论点 |
| 真实时间维度的演化验证 | 需要间隔数月的第二批采集，是数据缺口不是工程缺口 |
| 岗位库去冗余 | 已知 5.6 倍冗余，但它只影响实验构造，不影响方法论主张本身 |

## 3. 执行顺序与判定点

```
E1 解耦 ──┬─ 混合臂 ≥ 频次基线 ──→ E2 画像扩展 ──→ 重跑 E1
          │
          └─ 混合臂 < 频次基线 ──→ 跳过 E2，直接修订文档主张
                                    （粒度贡献改为「解决测量分辨率」而非「提升发现能力」）

E3 / E4 与 E1 无依赖，可并行；两者都是低成本的机械性验证。
```

**完成标志**：E1、E3、E4 全部有结论，且 E2 要么完成、要么因 E1 结论被明确跳过。
届时方法论的每一项主张都处于「已证 / 已测否定 / 明确声明无实证支持」三态之一，
不再有「只有解析论证但未验证」的悬空主张。
