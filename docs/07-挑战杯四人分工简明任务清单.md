# 挑战杯四人分工简明任务清单

> 适用范围：作品设计实现方案撰写、研究验证和挑战杯测试材料准备
> 分工粒度：最细到二级节，如 `4.1`、`6.2`
> 暂缓范围：第九章“系统部署与技术环境”暂不安排

## 一、分工总览

| 人员 | 负责章节与实验 | 核心任务 |
| --- | --- | --- |
| P1 | 第一章、第二章、第十章 | 负责项目背景、问题定义、总体设计、成果价值和全文总体口径 |
| P2 | 4.1、4.2、6.1、7.1 | 负责新岗位发现、既有岗位动态更新、岗位标准定义中心和创新点一 |
| P3 | 第三章、第五章、6.2、7.2；第八章JD提取测试实验 | 负责数据底座、知识图谱、全景图谱、幻觉防控和JD解析测试 |
| P4 | 4.3、6.3、7.3；第八章简历提取与人岗匹配实验 | 负责简历解析、匹配诊断、学习路径、创新点三及两项准确率实验 |

## 二、P1任务清单

### 负责内容

- 第一章：项目背景与问题定义。
- 第二章：系统总体设计。
- 第十章：项目总结与价值分析。

### 主要任务

- 梳理政策背景、产业痛点、项目目标和赛题要求。
- 统一项目总体架构、技术路线和数据流说明。
- 汇总P2、P3、P4提供的成果和实验数据。
- 编写项目成果、评分标准对应、社会价值、产业价值和未来展望。
- 统一全文项目名称、术语、技术版本、数据规模和指标口径。
- 正式实验完成前，不得将目标准确率写成实际达成结果。

## 三、P2任务清单

### 负责内容

- 4.1 新岗位发现与定义。
- 4.2 既有岗位能力动态更新。
- 6.1 岗位标准定义中心。
- 7.1 创新点一：主动式岗位动态定义。

### 主要任务

- 说明新岗位发现的输入、评分方法、成熟阶段、风险项和审核流程。
- 对比方案中的五级潜水机制与当前实现，明确保留、修改或改进方式。
- 梳理新岗位从发现、定义、审核到正式入库的完整闭环。
- 说明既有岗位能力新增、删除、增强、减弱和版本演化机制。
- 准备1个新岗位和1个既有岗位的完整案例。
- 为两个案例整理能力图谱、岗位数据源和输入输出示例。
- 完成创新点一的创新性、可行性和实际价值说明。

## 四、P3任务清单

### 负责内容

- 第三章：多源异构数据底座层。
- 第五章：动态知识图谱中枢层。
- 6.2 全景图谱洞察中心。
- 7.2 创新点二：全链路图谱化幻觉防控。
- 第八章中的JD提取测试实验。

### 主要任务

- 梳理数据准入、清洗、去重、来源管理、数据版本和血缘机制。
- 区分六库、Neo4j和Graph-RAG等内容的已实现、降级实现与后续规划状态。
- 说明技术词体系、图谱实体关系、图谱构建、动态展示和全景洞察功能。
- 梳理输入层去噪、生成层约束和输出层审核三层幻觉防控机制。
- 建立或参与冻结不少于100条岗位JD及测试用例。
- 制定JD字段标注规则，测试岗位名称、职责、必备技能、加分技能和应用场景的提取效果。
- 计算Precision、Recall、F1和混淆矩阵，验证JD解析准确率是否达到90%。
- 整理重复、抄袭、技能通胀、无原文证据和错误技术编码等失败案例。

## 五、P4任务清单

### 负责内容

- 4.3 匹配算法组。
- 6.3 人岗匹配诊断中心。
- 7.3 创新点三：全流程精准匹配导航。
- 第八章中的简历提取测试实验。
- 第八章中的人岗匹配准确率实验。

### 主要任务

- 梳理简历解析、人才画像、匹配评分、差距诊断和学习路径流程。
- 说明当前十维确定性评分与四维展示画像的对应关系。
- 区分必备技能、加分技能、可迁移技能和证据不足情况。
- 说明PDF、DOCX、TXT等格式的支持范围以及扫描件OCR边界。
- 建立脱敏简历字段标注集，测试姓名、学历、经历、项目和技能提取效果。
- 建立“简历—岗位”人工标注样本，测试匹配、部分匹配和不匹配判断。
- 计算Precision、Recall、F1和混淆矩阵。
- 验证简历提取准确率和人岗匹配准确率是否分别达到90%。
- 人工检查差距排序、改进建议和学习路径是否合理。
- 确保LLM只生成解释，不修改机械分数和事实。

## 六、第八章协作方式

- P3负责JD提取、数据可信和幻觉防控相关实验内容。
- P4负责简历提取、人岗匹配和学习路径相关实验内容。
- P2提供新岗位与既有岗位两个完整案例及其验证材料。
- P1将最终确认的实验指标同步到第十章，并统一全文数据口径。

比赛硬性测试要求如下：

- 提供不少于100条岗位JD及测试用例。
- JD解析准确率不低于90%。
- 简历提取准确率不低于90%。
- 人岗匹配准确率不低于90%。
- 单元测试覆盖率不低于60%。
- 提供1个新岗位和1个既有岗位的能力图谱、岗位数据源及输入输出示例。

## 七、统一交付要求

每人至少提交：

1. 所负责章节的完整文稿。
2. 一份算法或流程说明。
3. 一张可用于设计方案或PPT的流程图。
4. 一个真实案例或实验结果图。
5. 数据来源、运行方法、指标和失败案例说明。

所有准确率必须来自冻结测试集和可复现实验，合成数据只能用于边界测试，不能作为挑战杯正式准确率。

## 八、可直接转发的简版消息

挑战杯设计方案和实验任务暂按以下方式分工：P1负责第一章、第二章和第十章，主要完成项目背景、总体设计、成果总结及全文口径统一；P2负责4.1、4.2、6.1和7.1，主要完成新岗位发现、既有岗位动态更新、岗位标准定义和创新点一，并准备1个新岗位和1个既有岗位案例；P3负责第三章、第五章、6.2、7.2以及第八章JD提取测试，主要完成数据底座、知识图谱、幻觉防控和JD解析准确率实验；P4负责4.3、6.3、7.3以及第八章简历提取和人岗匹配准确率实验，主要完成简历解析、匹配诊断、差距分析和学习路径。第九章暂时不处理。第八章由P3、P4分别完成实验，P2提供两个岗位案例，P1根据最终结果统一第十章的数据口径。
