### 后端领域模块

| 模块 | 职责 |
| --- | --- |
| `ingestion` | 多源采集与合规抓取 |
| `extraction` | JD 结构化抽取 |
| `taxonomy` | 四级技术词体系与版本治理 |
| `job` | 岗位事实、解析运行与技术命中复核 |
| `clustering` | 岗位聚类与标准岗位版本 |
| `discovery` | 新岗位发现：库内推演、研究侧与产业侧缺口分析、候选审批 |
| `graph` | 图谱投影：岗位—能力、产业—岗位、技术—岗位 |
| `talent` | 人岗匹配、简历解析与发展路径 |
| `organization` | 机构主数据与产业链标注 |
| `data_center` | 数据源、里程碑、审核队列 |

## 技术栈

- 后端：Python 3.11 + FastAPI + SQLAlchemy 2 + Alembic + MySQL 8.0
- 前端：React 19 + TypeScript + Vite + AntV G6（图谱渲染）
- 部署：Docker Compose，Nginx 提供静态站与 `/api` 反向代理
- LLM：兼容 OpenAI 协议的网关（密钥从未入库的 `.env` 注入，不在代码中）
