# 需求提取文档（XH-202621 · 具身智能方向）

> **来源**：《XH-202621 多源异构数据驱动岗位和能力图谱构建与动态演化分析研究比赛方案》（科大讯飞发榜）
> **聚焦领域**：具身智能企业（人形机器人、灵巧抓取、Sim-to-Real、世界模型、VLA 等方向）
> **功能分层**：底线功能（赛题硬性要求）/ 完备功能（底线功能的优化完善，丰富体验）/ 扩展性功能（超出赛题要求）

---

## 一、赛题核心要求摘要

赛题要求构建一套"数据驱动 + 大模型 + 知识图谱"的岗位能力动态演化与分析系统，形成
**"新岗位发现与定义 → 既有岗位能力动态更新 → 全景图谱可视化 → 人岗匹配诊断 → 改进建议与学习路径规划"** 的全流程闭环。

三大核心难题：

1. 从海量多源数据中精准发现并定义新兴岗位，构建可动态更新的岗位能力图谱；
2. 解决招聘数据的"时滞""噪声""抄袭"问题，防控 LLM 生成内容的"幻觉"；
3. 高精度简历解析与细粒度人岗差距分析。

量化硬指标：

| 指标 | 要求 |
|---|---|
| JD 解析准确率 | ≥ 90% |
| 简历技能提取准确率 | ≥ 90% |
| 人岗匹配准确率 | ≥ 90% |
| 岗位 JD 及测试用例 | ≥ 100 条 |
| 单元测试覆盖率 | ≥ 60% |
| 部署 | Dockerfile 或容器化部署 |

---

## 二、底线功能（必须实现，缺失即重大扣分）

> 对应评分标准中"作品完整性（30 分）"与"实用价值（30 分）"的硬性条款。

### D1. 多源数据采集与导入
- 支持具身智能企业招聘 JD 的采集/导入（岗位名、公司、城市、薪资、经验、学历、JD 正文、来源平台、收录时间）；
- 支持技术词典/技能本体等异构数据源导入；
- 岗位 JD 数据量满足 ≥100 条测试要求。

### D2. 新岗位发现与定义
- 从 JD 数据中识别正在萌芽、尚未标准化的新兴岗位（如 VLA 算法工程师、Sim-to-Real 工程师、世界模型研究员）；
- 生成五要素岗位定义：**岗位名称、核心职责、必备技能、加分技能、典型行业应用场景**；
- 支持人工优化与动态更新。

### D3. 既有岗位能力动态更新
- 针对现有岗位（如机器人算法工程师）识别能力要求变化；
- 提供**更新说明及数据源**；
- 明确标注岗位能力项的**新增 / 删除 / 修改**；
- 支持人工优化与动态更新演化。

### D4. 新一代信息技术岗位全景图谱
- 展示领域内岗位的能力要求，颗粒度到**"技能点"级别**；
- 支持**按技术栈切换视图**；
- 支持**按级别（初级/中级/高级）切换视图**。

### D5. 简历解析
- 支持 PDF/Word 等格式简历解析；
- 提取简历技能要素并归一到统一技能本体；
- 提取准确率 ≥ 90%。

### D6. 人岗匹配度诊断与差距分析
- 用户输入技能数据（或上传简历），系统对比目标岗位图谱；
- 输出差距分析（已具备 / 缺失技能）；
- 支持多维度匹配分析；
- 匹配准确率 ≥ 90%。

### D7. 针对性改进建议与岗位学习路径规划
- 基于差距分析结果给出针对性改进建议；
- 提供面向目标岗位的学习路径规划。

### D8. 能力"幻觉"防控（创新性硬要求）
- LLM 抽取/生成结果必须有防控机制，防止无证据的技能/岗位凭空进入图谱；
- 防控方案需完善、可演示、可验证。

### D9. 可验证性与交付物
- 完整测试方案（≥100 条岗位 JD 及测试用例），三项准确率可量化验证；
- 单元测试覆盖率 ≥ 60%；
- 源代码 + 部署说明（Dockerfile/容器化）；
- 材料文档：设计方案、PPT、≤10 分钟演示视频（含新岗位与既有岗位能力更新演示）；
- 提交 1 个新岗位 + 1 个既有岗位的能力图谱及岗位数据源（含输入输出示例）。

## 三、完备功能（底线功能的优化完善，丰富体验）

> 对应评分标准中"用户体验（15 分）"与"技术创新性（25 分）"的完善项，不做不扣大分，做了显著提升完成度与体验。

### C1. 多源异构数据清洗与交叉验证
- JD 幂等去重（解决重复采集/抄袭问题）；
- 数据时滞识别：按收录时间窗口过滤陈旧 JD，展示数据新鲜度；
- 多源交叉验证：同一技能需证据支撑（JD 原文片段可回溯）方可进入正式图谱。

### C2. 幻觉防控工程化闭环
- 证据溯源：每条"岗位—技能"边可回溯 JD 原文证据片段；
- 置信度门限：高置信确定性结果自动放行，低置信/LLM 生成结果强制待审；
- 人工审核工作台：待审队列（图谱边 / 聚类命名 / 岗位定义）、通过/驳回裁决、审核日志留痕；
- "未审核不入正式表"原则贯穿图谱展示与匹配计算。

### C3. 图谱可视化交互增强
- 力导向图布局 + 节点/边权重可视化（需求热度、技能类型着色）；
- 节点点击详情（岗位画像、技能关联岗位列表）；
- 分类 / 级别 / 技能类型多维筛选联动；
- 大规模数据下的渲染性能优化（节点配额、Top-N 采样）。

### C4. 匹配诊断体验完善
- 匹配得分分量拆解（技能余弦 / 领域分布 / 核心技能 Jaccard / 头衔相似度），结果可解释；
- 差距清单严重度分档（核心缺失 vs 加分项缺失）；
- 技术域筛选（限定匹配范围到具身智能某子域）；
- 简历历史记录与复用。

### C5. 新岗位发现流程完善
- 聚类结果携带共享技能、代表岗位标题、关键词、命名来源、数据新鲜度；
- 候选区与已审核区分离展示；
- 一键从聚类生成五要素定义并进入审核流。

### C6. 能力演化过程管理
- 岗位能力快照与版本管理；
- 快照差分可视化（新增/删除/修改标注 + 更新说明）；
- JD 更新后重提取并自动产生差分。

### C7. 大模型降级与鲁棒性
- LLM 未配置/不可用时自动降级为规则方案，不伪造 LLM 结果；
- 简历扫描件/空文本等异常输入友好报错；
- 管线幂等可重跑（重复导入/提取不产生脏数据）。

## 四、扩展性功能（超出赛题要求）

> 赛题未要求，但可体现技术纵深与具身智能领域专精的差异化能力。

### E1. 技能需求热力图
- 按"技能类目 × 职级"呈现具身智能领域近期活跃岗位的技能需求强度；
- 支持时间窗口切换（如近 90/180/365 天），直观回答"哪些技能在爆发"。

### E2. 技术趋势预警与竞对洞察
- 基于图谱演化数据识别快速上升的技能/岗位，输出技术预警；
- 具身智能企业维度分析（融资阶段、地区分布、岗位结构），辅助产业洞察。

### E3. 语义向量匹配（RAG 方向）
- 在稀疏向量混合匹配之上引入语义向量（如 bge-small-zh），支持同义词/近义技能匹配；
- 语义分与稀疏分透明融合，模型不可用时透明降级。

### E4. 岗位任务生成与培养链路
- 从岗位能力图谱反向生成培养任务（定制任务库 → LLM 动态生成 → 兜底模板三级链路）；
- 任务组映射岗位名称，支撑"学习路径规划"的具身智能场景化落地。

### E5. 跨领域可迁移性验证
- 管线在具身智能（T1–T7）之外的新一代信息技术四域（AI/大数据/物联网/智能系统）上复用验证，证明方案可迁移。

### E6. 岗位能力图谱导出与数据资产化
- 新岗位/既有岗位图谱及数据源的标准化导出（输入输出示例包），直接满足赛题测试数据提交要求，并可作为行业数据资产沉淀。

## 五、需求优先级总览

| 层级 | 数量 | 定位 | 验收口径 |
|---|---|---|---|
| 底线功能 D1–D9 | 9 项 | 缺一不可 | 三项准确率 ≥90%、全流程闭环可演示 |
| 完备功能 C1–C7 | 7 项 | 体验与创新完善 | 审核闭环可操作、交互流畅、降级可验证 |
| 扩展功能 E1–E6 | 6 项 | 差异化竞争力 | 演示加分项，逐项独立可展示 |
