# 岗位能力关联图 G6 引擎迁移实施报告

## 迁移目标

将岗位—能力关联页从前端自研的 SVG 固定径向布局迁移到 AntV G6 5.1.1 力导向渲染，解决节点数量增加后重叠、边关系不直观和缺乏物理交互的问题。迁移不改变后端岗位聚类、能力关键词、证据和筛选口径。

## 已执行内容

1. 前端新增 `@antv/g6@5.1.1`，新增 `ForceRelationGraph` 组件。
2. 岗位聚类使用矩形节点，标准技术能力使用圆形节点；T1–T7 领域颜色沿用现有主数据色板。
3. 启用 `force` 布局与节点避让、画布缩放/拖拽、节点拖拽、点击选中和悬停激活；边宽度与透明度映射关系重要性。
4. 详情检查器仍由现有 React 页面负责，点击 G6 节点后继续展示证据数量、关联节点和目标日期。
5. 关系接口请求上限从 12 个岗位聚类/每簇 8 项能力提升为 30 个岗位聚类/每簇 12 项能力；表格视图保留为大数据量和无 Canvas 环境的降级入口。
6. 接口 `rendering` 元数据更新为 `primary_route=g6_force`、`layout_owner=frontend_g6_force`。

## 验收结果

- `frontend`: `pnpm run build` 通过。
- `backend`: `backend/.venv/bin/python -m pytest -q`，43 passed；Ruff 检查通过。
- Docker: 前端、后端、MySQL 重建并启动，健康检查正常。
- API: `cluster_limit=30`、`capabilities_per_cluster=12` 生效；岗位聚类领域和能力领域/层级仍独立返回。
- 页面: G6 画布成功挂载；T2 能力筛选不会缩窄岗位聚类，之后选择 T1 岗位聚类仍保留 T2 能力筛选；表格视图可切换。
- 浏览器控制台: 新开页面验收无新增错误。

## 后续扩展

- 当节点规模超过当前 API 上限时，再增加分页/分层加载或 Sigma.js WebGL 总览视图，不在本次迁移中混合引入第二套渲染引擎。
- 可根据真实用户反馈调整力导向参数、标签显示阈值和移动端节点密度。
