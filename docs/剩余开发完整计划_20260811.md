### 3.4 阶段 D：外部适配与多模态（08-20 — 08-25）

对应差距：G5、G6、G7、G8。顺序：多格式简历 → 文件安全 → 真实采集 → LLM → 认证隐私。

任务：

1. **PDF/DOCX/TXT 文件上传与解析**（G6）：新增文件上传端点（替代纯文本入参），pypdf/python-docx 适配器，解析证据入库；OCR 用适配器占位 + 可替换实现（首期允许降级为"扫描件提示转文本"）；
2. **文件安全**（G6）：MIME 嗅探、大小限制、扩展名白名单、病毒扫描接口预留、旧 DOC 隔离流程；
3. **真实网页采集最小闭环**（G7）：实现至少 1 个合规公开来源的采集适配器（列表→详情一层深入）、请求留痕、内容哈希增量判断与 missing_once/suspected_expired 状态；调度首期用进程内定时任务，显式记录"Worker 后置"决策；
4. **LLM 网关**（G5）：OpenAI 兼容适配器（默认 DeepSeek，支持无 Key 降级为规则）；统一结构化输出 Schema 校验、`evidence_ids` 回指检查、模型/Prompt 版本入库；接入三处：新岗位表达优化、简历追问生成、匹配解释；LLM 不进入机械评分；
5. **认证授权**（G8）：最小 JWT 登录 + reviewer/admin/user 三角色，审核与写操作强制鉴权，访问审计表；
6. **隐私操作**（G8）：简历与画像删除请求（软删 + 派生结果失效标记）、导出脱敏。

验收：

- 至少三种简历格式（文本 PDF、DOCX、TXT）解析样例各一条并绑定原文证据；
- 一个真实数据源完成手工 + 定时各一次采集，页面未变化不产生新版本；
- 无 LLM Key 时系统全部核心流程不中断（降级路径有测试）；
- 未登录调用写接口返回 401。
