# 前端设计方案与开发计划

> 项目：具身智能岗位能力图谱系统  
> 版本：v1.0  
> 日期：2026-08-08

---

## 一、全局设计规范

### 1.1 布局结构

- **导航方式**：侧边栏（Sidebar）
- **视觉风格**：浅色简洁风
- **前端框架**：Next.js + React
- **UI组件库**：shadcn/ui
- **图谱渲染**：AntV G6

### 1.2 侧边栏导航

```
具身智能岗位能力图谱
├── 📊 数据总览（Dashboard）
├── 📡 数据采集
├── 🔍 新岗位发现
├── 🏷️ 岗位聚类管理
├── 🕸️ 能力图谱
├── 📄 简历匹配
└── ⚙️ 系统设置
```

### 1.3 数据层级说明

```
岗位体系（同级但分离存储）
├── 新发现岗位（独立表）← 新岗位发现模块产出
└── 岗位聚类（独立表）  ← JD聚类模块产出
```

## 二、页面详细设计

### 2.1 数据总览（Dashboard）

**三栏布局**：

```
┌────────────┬─────────────────────────┬────────────┐
│  左侧面板   │       中央图谱区         │  右侧面板   │
│            │                         │            │
│ · 节点列表  │   能力图谱可视化渲染      │ · 节点详情  │
│ · 筛选/搜索 │   (AntV G6)             │ · 关联数据  │
│ · 树形结构  │                         │ · 操作按钮  │
│            │                         │            │
└────────────┴─────────────────────────┴────────────┘
│  底部：统计卡片（JD数、技术词数、聚类数、更新时间）    │
└──────────────────────────────────────────────────────┘
```

- 左侧：可切换节点列表（按聚类/技术栈/级别过滤）
- 中央：图谱渲染区，支持视图模式切换
- 右侧：选中节点详情、关联关系、快捷操作

**视图切换**：全景 / 关联图 / 热力图 / 演进图

---

### 2.2 数据采集

| Tab | 功能 |
|-----|------|
| 爬取目标 | 目标表格管理（URL、类型、频率、状态），支持启停 |
| 采集记录 | 历史爬取日志，展示时间/状态/新增数量 |
| 数据预览 | 原始数据 vs LLM提取结果对比展示 |
| 手动导入 | 文件上传 + 文本粘贴输入 |

---

### 2.3 新岗位发现（独立模块）

| Tab | 功能 |
|-----|------|
| 候选岗位 | 算法检测到的疑似新岗位，卡片列表 |
| 岗位详情 | 完整定义（卡片/完整JD切换） |
| 发现历史 | 已确认的新岗位记录 |

**岗位卡片组件**：
- 岗位名称 + 置信度标签
- 核心职责摘要
- 必备/加分技能标签
- 关联里程碑
- 操作按钮：编辑 / 确认入库 / 拒绝 / 细化为JD

---

### 2.4 岗位聚类管理（独立模块）

| Tab | 功能 |
|-----|------|
| 聚类总览 | 所有聚类列表 + JD数量/技术词数统计 |
| 聚类详情 | 选中聚类的能力需求集、频率分布图 |
| 能力更新 | 变更事件流（新增/删除/修改）+ 数据源标注 |
| 审批队列 | 待审批新聚类（LLM评分低） |
| 趋势分析 | 技术词频率趋势、淘汰预警、岗位热度 |

---

### 2.5 能力图谱

- 沉浸式全屏图谱浏览
- 工具栏：导出图片、截图、对比模式、布局切换
- 与Dashboard嵌入版共用渲染组件
- 支持搜索定位、缩放、拖拽

---

### 2.6 简历匹配（多Tab）

| Tab | 功能 |
|-----|------|
| 上传简历 | 拖拽上传(PDF/DOC/TXT) + 文本输入 + 解析进度 |
| 求职者画像 | 结构化数据 + 语义画像展示，支持手动修正 |
| 对话交互 | LLM追问聊天界面，实时更新画像 |
| 匹配分析 | 目标选择 + 雷达图 + 差距列表 + 改进路径 |

---

### 2.7 系统设置

| Tab | 功能 |
|-----|------|
| LLM配置 | API Key、模型选择、温度、上下文长度 |
| 调度配置 | 爬取频率、Cron表达式 |
| 算法参数 | 阈值（相似度、置信度、覆盖率、衰减系数等） |
| 数据管理 | 数据导入/导出/初始化/重置 |

---
