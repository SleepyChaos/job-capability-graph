## 2. 三项准确率测试（赛题要求各 ≥90%）

真值：120 条样例 JD 的内置标注（`make_sample_jds.py` 生成，含真值字段）。

| 指标 | 结果 | 达标 |
|---|---|---|
| Precision | **95.71%**（TP=1071 / FP=48） | ✅ |
| Recall | **100.00%**（FN=0） | ✅ |
| F1 | **97.81%** | ✅ |

> FP=48 为迁移时已入库的指标词噪声边（合成样本固有，与本次改动无关）；实测 F1 97.81% 仍达标。
> 运行方式：`python3 -m pipeline.eval_extraction`

| 指标 | 结果 | 达标 |

| 文本内真值 Recall | **100.0%**（205/205） | ✅ |

> 字面不存在于简历文本，无法从文本提取，不计入 Recall 分母（口径已文档化于评测脚本 docstring）。

## 4. 已知问题与说明

1. 浏览器自动化（视觉回归）在本机存在 0×0 视口环境故障，前端页面以 HTTP 200 + `tsc --noEmit` + DOM 快照验证代替。
2. LLM 链路（岗位定义生成/聚类命名增强）未配置 Key 时自动降级规则方案，评测均为降级模式实测；
   配置 `OPENAI_API_KEY` 后 LLM 输出同样受"未审核不入正式表"约束（job_definitions 一律 pending）。
3. 图谱页力导向仿真在 ~400 节点时主线程占用高（项目一原生 O(n²) 斥力），已记录为后续优化项（Barnes-Hut），不阻塞交付。
