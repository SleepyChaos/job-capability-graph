## 1. 任务定位

量化当前技术抽取的准确率与召回率,回答:**「7,591 条技术证据里,有多少是对的、漏了多少」**。
你的结论直接决定窗口 B(`feat/taxonomy-v2-rebuild`)是"修词表"还是"重做抽取",所以**结论必须可复现、口径必须写清楚**。

产出物是分析脚本(`tools/`)+ 报告(`docs/reports/`)。

### 明确不做的事

- 不下线/修改任何表面词(那是窗口 B 拿着你的清单去做)

- 不调聚类参数
- 不执行 `parse_jobs` / `cluster_jobs` / `discover_roles` / `reassess_technologies_llm`

## 3. 实施步骤

### 3.1 子任务 1.1:过宽表面词排查

1. **统计**:按 `md_technology_alias` 聚合最近运行内每个别名的:命中次数、命中 JD 数、
   `alias_text` 长度、映射目标节点(`level_code` + `technology_name`)。
   注意区分「评估状态」口径:分别统计 accepted 与 needs_review。
2. **判定过宽**(07 任务书标准):
   - 命中文本 ≤3 字且语义宽泛(如"检测"、"汽车"、"大模型")
   - 同一命中文本在不同语境下应指向不同技术点
   - 通用领域词被挂到具体技术点
   - 反向问题也记录:超长学术术语(393 个 L4 词 >15 字)完全无命中——这是 1.2/窗口 B 的输入
3. **评估现有 4 条歧义规则的实际效果**:每条规则产生了多少 needs_review?
   LLM 复核后的接受率?哪些词走了"语境命中 80 分"路径被 accepted 但实际是误报?
4. **输出**:`docs/reports/过宽表面词排查报告.md`,含
   过宽词清单(每条:词、命中次数、映射目标、建议动作【下线 is_matchable=False / 收窄加语境 / 维持】、
   影响证据条数)+ 汇总统计。配套 SQL/分析脚本进 `tools/`。

### 3.2 子任务 1.2:L3 覆盖盲区排查

1. **语料**:最近运行内 1,546 份有证据 JD + 2,111 份零证据 JD 的正文
   (JD 正文在 `biz_job_posting` 相关表,先读 `backend/app/modules/job/models.py` 确认字段)。
2. **方法**:高频词/词组抽取 → 减去 `md_technology_alias.normalized_alias` 已有词 →
   排除通用编程/办公词(**维护一个显式停用词清单文件**并提交:python/java/linux/git/sql/
   excel/office 等,07 任务书明确这类词不在具身智能词表范围)→ 人工判读归并为候选技术点。
3. **已知线索**(优先核实):TensorRT、vLLM、ONNX Runtime、CUDA、KV Cache、FP8 量化、
   Jetson Orin(→ 应挂 `T1.01.06` 方向)、Sim2Real、模型量化、端侧部署。
4. **输出**:`docs/reports/L3覆盖盲区排查报告.md`,候选新增技术点按频次排序,
   每条标注:出现频次、出现 JD 数、建议挂载的 L2 父节点、置信说明。

### 3.3 子任务 1.3:人工标注对照(两阶段,本分支只做阶段 a)

- **阶段 a(本分支交付)**:
  1. 用现有工具 `backend/tools/build_jd_annotation_batch.py` 生成标注包
     (参数:`--run-code`、`--sample-count 50~100`、`--per-domain-min`,先读脚本确认行为)
  2. 分层覆盖:具身算法岗 / 硬件岗 / 工程岗 / 非技术岗各若干
  3. 定义标注格式(每份 JD:人工认定应抽出的 L3 技术点列表 + 标注说明文档)
  4. 写对照评估脚本 `tools/evaluate_extraction_quality.py`:标注 vs 实际抽取,
     输出 Precision / Recall / F1,**按岗位类型分层**,附 bootstrap 置信区间
- **阶段 b(人工,不在本分支)**:标注由人完成;报告须声明标注者身份、是否双人标注。
  评估脚本在标注包回填后即可产出指标报告——脚本要用合成标注数据自测通过。

### 3.4 总报告

`docs/reports/抽取质量评估总报告.md`:整合 1.1/1.2/1.3 结论,直接回答
