## 2. 岗位缺口检测算法 — "覆盖率"计算方式

### 核心问题
如何量化"技术词组合的JD覆盖率"来判定是否存在新岗位缺口？

### 需要回答的子问题
- [ ] 覆盖率的具体计算公式是什么？
- [ ] 技术词组合如何确定？（共现分析？预设组合？）
- [ ] 里程碑事件如何影响权重？
- [ ] 阈值如何设定？（低于多少覆盖率判定为缺口）
- [ ] 是否需要时间窗口？（如最近N天的JD才纳入统计）
- [ ] 如何区分"真缺口"和"数据不足"？

### 初步思路（待验证）
```
覆盖率 = 包含该技术词组合的JD数量 / 该技术词组合出现的总频率
如果覆盖率 < 阈值 且 里程碑已达成 → 触发新岗位发现流程
```
