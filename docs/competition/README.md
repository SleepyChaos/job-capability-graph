## SVG 插入 Word 的方式

Word 2016 及以上：插入 → 图片 → 选择 .svg 文件。插入后可右键「转换为形状」以微调文字。
若目标 Word 版本不支持 SVG，用浏览器打开 SVG 截图另存为 PNG 即可（图形均为矢量文字，放大不失真）。
