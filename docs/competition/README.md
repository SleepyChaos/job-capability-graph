## SVG 插入 Word 的方式

Word 2016 及以上：插入 → 图片 → 选择 .svg 文件。插入后可右键「转换为形状」以微调文字。
若目标 Word 版本不支持 SVG，用浏览器打开 SVG 截图另存为 PNG 即可（图形均为矢量文字，放大不失真）。

### 关于「未实测的数字」

竞赛文档最容易出问题的地方是把设计目标写成已达成指标。建议全文检索这几类表述并逐一核实：
准确率 / 召回率 / F1 / 响应时间 / 提前预警时长 / 覆盖率 / 一致性。凡是我们没有实测过的，
要么删除，要么改写为设计目标并明确标注"目标值，待验证"。
