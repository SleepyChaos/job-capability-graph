# 具身图谱前端 Mock

纯前端交互原型，使用 React、TypeScript、Vite 和本地 Mock 数据实现，不依赖后端服务。

## 本地运行

```bash
pnpm install
pnpm dev
```

默认地址：`http://127.0.0.1:4173/`

生产构建：

```bash
pnpm build
```

## 已实现页面

- 系统总览
- 数据中心
  - 数据采集中枢
  - 数据管理中心
  - 技术词标准管理
  - 数据审核中心
- 新岗位发现
  - 技术词定向推演
  - 岗位名称推演
  - 推演结果记录库
- 动态能力图谱
  - 能力热力图
  - 岗位—能力关联图
  - 聚类岗位能力图谱
- 人岗匹配
  - 求职者画像
  - 匹配分析
  - 发展路径

## 可演示交互

- 在桌面端将左侧导航收起为图标栏并再次展开，移动端保持完整抽屉导航；
- 运行增量采集并查看完成提示；
- 查看数据清洗、幻觉防范、置信度分流、JD 聚类及关键词/里程碑 T/L 分类流程；
- 在新岗位发现首页查看综合自动预测候选，并在独立流程中审批入库；
- 在三个缩进子页面分别进行技术词定向推演、岗位名称推演和历史推演记录管理；
- 在能力图谱主页查看总体变化，并通过三个缩进子页分别探索热力矩阵、岗位—能力关系和岗位聚类能力结构；
- 在图谱子页切换 T1–T7、L1–L4、技术栈和时间窗口，查看节点、单元格与聚类证据；
- 从纯净对话入口上传简历，通过 2–8 轮自适应追问生成画像并模拟入库；
- 在画像库浏览历史画像、切换当前画像，修改后生成新版本并保留旧记录；
- 使用选中画像生成 JD 匹配结果，点击结果展开绑定的差距；
- 筛选差距、补充证据、重新计算匹配并由差距生成发展路径；
- 标记学习路径步骤完成；
- 对低置信度 JD、关键词、里程碑和分类结果执行通过、观察或驳回。

设计基线见 `../design/DESIGN_SYSTEM.md`，概念稿位于 `../design/concepts/`。
