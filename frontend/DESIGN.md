# DESIGN.md

## 项目定位
新一代信息技术岗位图谱系统 — 专业 B 端数据可视化平台，面向人力资源与产业研究场景。

## 气质与意象
- 关键词：专业、精准、数据驱动、可信赖
- 意象：深夜指挥中心，深蓝大屏上流动着节点与连线，数据如脉搏般闪烁
- 风格：克制的科技感，不浮夸，信息密度高但层次清晰

## Design Tokens

### 色彩
- 主色：`#2563EB`（深蓝）— 权威、信赖
- 辅助色：`#7C3AED`（紫罗兰）— 智能、前沿
- 背景：`#F8FAFC`（极浅灰蓝）— 干净不刺眼
- 卡片背景：`#FFFFFF`
- 导航栏：`#0F172A`（深墨蓝）
- 状态色：
  - 成功/新增：`#10B981`（翠绿）
  - 警告/修改：`#F59E0B`（琥珀）
  - 危险/删除：`#EF4444`（红色）
  - 信息：`#3B82F6`（蓝）
- 文本色：
  - 主文本：`#1E293B`
  - 次文本：`#64748B`
  - 弱文本：`#94A3B8`

### 字体
- 中文：PingFang SC, Microsoft YaHei
- 英文/数字：Inter, system-ui
- 数据展示：JetBrains Mono（等宽）

### 圆角
- 卡片：`12px`
- 按钮：`8px`
- 标签：`6px`
- 输入框：`8px`

### 阴影
- 卡片：`0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)`
- 悬浮：`0 10px 15px -3px rgba(0,0,0,0.08), 0 4px 6px -2px rgba(0,0,0,0.04)`

## 布局规范
- 顶部导航栏：高度 56px，深色背景 `#0F172A`
- 左侧边栏：宽度 240px，可折叠，浅色背景
- 内容区：`padding: 24px`，最大宽度不限
- 卡片间距：`16px`

## 交互规范
- 过渡动画：`transition: all 0.2s ease`
- 悬浮反馈：卡片微上浮 `translateY(-2px)` + 阴影增强
- 选中态：左侧边栏项左侧 3px 主色条

## 设计禁忌
- 不要使用大面积渐变色背景
- 不要使用过于卡通化的图标
- 不要使用超过 3 种主色调
- 不要使用纯黑色（#000000），用深墨蓝替代
