# Layer C 三元组人工真值规范 v1.0（冻结版）

## 判断标签

- `correct`：主体—关系—客体可由所列JD证据直接支持。
- `incorrect`：关系与证据冲突、主体归属错误、技术映射错误或方向错误。
- `insufficient_evidence`：仅凭当前证据不能判断；不能强行作为正确或错误。

标注员必须查看支持JD原文，不能只看主体和技术名称。低支持度不等于错误，知名企业常识也不能替代数据证据。

## 冻结抽样

- 从同一 `audit_run_code` 的 low、medium、high 各抽50条，共150条。
- 各档内部按三元组稳定哈希排序，不按人工偏好挑样。
- A、B独立标注；不一致项必须仲裁。
- 阈值校准只使用仲裁后的 `correct/incorrect`，`insufficient_evidence`单独报告并排除训练。

## 校准与报告

- 任务定义：`plausibility_score < threshold` 预测为错误边。
- 在0.01至0.99上搜索阈值，主指标为错误边F1；F1并列时选择Precision更高、再选择更低阈值。
- 同时报告混淆矩阵、Precision、Recall、F1和被排除的证据不足数量。
- 校准集只能用于选阈值，正式准确性还需独立留出验证集；不得把本集结果称为最终泛化准确率。
