# 能力图谱 + 技术图谱 构建报告

> 生成时间：2026-08-22 · 数据口径：真实数据（来源见下）

## 一、一句话总结

基于 **3718 条岗位 JD、634 家具身智能企业、2151 个技术词（L1-L4）**，构建出一张 **4719 个节点、9562 条边**的双域图谱：技术域（技术点 L3→L2→L1）与能力域（岗位→能力项→技能族）各自成图，通过「技能族 → 技术域 L2」桥梁连接。

## 五、关键口径说明

1. **能力等级是岗位的独立属性，不是「域」**：岗位节点携带 `level` 字段（初级 166 / 中级 1,692 / 高级 1,860），来自岗位数据已有字段。
2. **技术点与能力项是两个粒度**：技术点（L3，如「VLA端到端大模型」「触觉世界模型」）是技术方向；能力项（如 Python、ROS、UART、深度学习）是工具与算法技能。二者通过「技能族→技术域」粗映射连接，不做 78→229 的强行细映射。
3. **技能标签覆盖率 47.7%**：3,718 个岗位中 1,772 个有技能标签。有标签岗位已覆盖 14/17 个职业种类，其中算法/软件/控制/视觉类覆盖率高（87%-100%），硬件/测试/运维类覆盖率低（8%-30%）。低覆盖的两点原因：① 部分非技术岗（HR/财务/审计/物流商务）被职业分类误归入技术类，本不该有技能标签；② 技术岗的 JD 术语（SMT/PCBA/FCT）比 78 个能力项更细，规则匹配覆盖不到。技能标签的 78 个唯一值与技能树字典 78 项 100% 重合。
4. **企业→岗位匹配 53/632**：岗位数据含大量海外公司（Figure AI、1X Technologies、Google DeepMind 等），不在国内 634 家企业库内，故匹配率有限；国内头部具身企业（蓝思、智元、宇树、优必选等）均已正确关联。
5. **L4 层（1,872 个具体模型/论文术语）暂不建节点**：粒度过细（如「GR00T N1」「ACT」），作为技术词表保留，图谱以 L1-L3 为主体。
