# 能力图谱 + 技术图谱 构建报告

> 生成时间：2026-08-22 · 最近更新：2026-08-27（合并权威技术词主数据 v1.1 + 科研助理 L2L3 分类结果）· 数据口径：真实数据（来源见下）

## 一、一句话总结

基于 **4,655 条岗位 JD（含技能标签与 L2/L3 技术分类）、634 家具身智能企业、2,151 个技术词（L1-L4）**，构建出一张 **7,528 个节点、24,692 条边**的双域图谱：技术域（技术点 L4→L3→L2→L1）与能力域（岗位→能力项→技能族）各自成图，通过「技能族 → 技术域 L2」桥梁连接；并在「技术—岗位图谱（图谱二）」维度新增 **岗位 → 技术类(L2/L3) 的直接分类边（带命中词/匹配方式证据）**。

## 五、技术—岗位图谱（图谱二）数据更新说明（2026-08-27）

本次合并了权威的《技术标注规范 v1.1》主数据（`技术词主数据_20260727.xlsx`）与 Coze Drive 产出的《科研助理岗位 L2L3 分类结果》，对「技术—岗位图谱」维度做了以下增强：

1. **L4 表面词正式建节点**：原 1,872 个 L4 表面词（`技术词主数据` 中的具体模型/论文/产品术语，如 π₀、OpenVLA、GR00T N1.7）由「仅统计」升级为图节点，挂在对应 L3 下（`belongs_to`）。技术域由此形成完整 **L1(7)→L2(43)→L3(229)→L4(1872)** 四层技术坐标系。
2. **岗位全量扩展至 4,655**：以 occ_id 为键对齐，在原有 3,718 岗位基础上补入 Coze Drive 中 937 条此前未入图的岗位（含海外/代招主体），公司能精确命中现有企业节点时补 `posts_job` 边。
3. **岗位→技术类直接分类边（图谱二核心）**：为全部 4,655 岗位依据分类结果生成 `classified_to_L2`（10,468 条）/ `classified_to_L3`（2,065 条）直接边，每条边携带 `method`（L4精确匹配 / L2正则匹配 / 职业方向兜底）与 `hit_words`（实际命中的技术词或正则串）作为可追溯证据——满足「每条连线都能回到 JD 原文/命中词」。
   - 4,583 / 4,655（98.5%）岗位至少有 1 条 L2 分类边；
   - 2,065 / 4,655（44.4%）岗位有 L3 精确实测分类。
4. **保留原有能力域桥接**：`requires_capability` / `belongs_to_family` / `supports_domain` 等原有边全部保留，技术—岗位图谱与能力域图谱共用同一套技术主数据坐标。

## 六、关键口径说明

1. **能力等级是岗位的独立属性，不是「域」**：原 3,718 岗位节点携带 `level` 字段（初级 166 / 中级 1,692 / 高级 1,860）；Coze 扩展的 937 岗位未含该字段（来源表无此列），不影响技术—岗位分类。
2. **技术点与能力项是两个粒度**：技术点（L3，如「VLA端到端大模型」「触觉世界模型」）是技术方向；能力项（如 Python、ROS、UART、深度学习）是工具与算法技能。二者通过「技能族→技术域」粗映射连接，不做 78→229 的强行细映射。
3. **L4 层已建节点**：原口径「L4 暂不建节点」已变更——按《技术标注规范 v1.1》「一词不删、全部安置」原则，1,872 个 L4 表面词全部挂接到 L3 下，闭包完整（226 个父 L3 编码 100% 命中现有 L3）。
4. **企业→岗位匹配 53/632（基础集）**：岗位数据含大量海外公司，不在国内 634 家企业库内；Coze 扩展集补入 725 条 `posts_job`（28 家新公司精确命中）。
5. **分类边证据可回查**：`classified_to_L2/L3` 边的 `hit_words` 字段记录了实际命中技术词或匹配正则，可在下游可视化中作为 JD 原文级证据展示。
